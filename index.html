Konfigurasi URL Google Apps Script

Masukkan URL Web App hasil deployment Google Apps Script Anda di bawah ini agar website di GitHub Pages dapat berkomunikasi dengan Google Spreadsheet.

Cara Memperoleh URL Deployment:

  1. Buka Google Apps Script tempat Anda menempelkan kode `Code.gs`.
  2. Klik Deploy > New deployment.
  3. Pilih type: Web App.
  4. Set Execute as: Me.
  5. Set Who has access: Anyone (Sangat penting!).
  6. Salin URL Web App dan tempelkan di atas.
